# Game Store

Виртуальный каталог игрового магазина: список игр, добавление и удаление позиций.

## Возможности

- Каталог игр с платформой, ценой (в долларах), статусом и поддержкой контроллера
- Добавление новой игры через форму
- Удаление игр из каталога
- Платформы: PC / PS5 / Xbox / Switch
- Статусы: Доступна / Скоро / Скидка
- Поддержка геймпада: да / нет

## Стек

- React 19
- Vite 8 (с React Compiler)
- ESLint 10

## Запуск

```bash
npm install
npm run dev
